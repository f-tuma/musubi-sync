# musubi-sync

Open-source sync core that unifies calendars, tasks and contacts from Google,
Microsoft, Apple iCloud and generic CalDAV/CardDAV into one store, keeps one
record in several places at once, and gives applications fast reads and a
change feed. Musubi is built on top of it.

Status: phase 1 in progress: workspace skeleton and interfaces (checkpoint K0).
See [docs/architecture/proposal.md](docs/architecture/proposal.md) and
[docs/plan/phase1.md](docs/plan/phase1.md) (Czech), and
[CONTRIBUTING.md](CONTRIBUTING.md).
